_- Pasos realizados para limpiar y cargar los datos:_

**1. Por medio de Python se toma el archivo Support_DB.csv:**

El archivo tiene mezcla de delimitadores:

Las 3 primeras columnas venían separadas por coma , (ticket_id, day_of_week, day_of_week_num).

El resto de las columnas venían separadas por pipe |.

Se implementó un parser para unificar los delimitadores:

`def parse_mixed_delimiter(path):     rows = []     with open(path, "r", encoding="utf-8-sig") as f:         for raw_line in f:             line = raw_line.rstrip("\n\r")             if not line:                 continue              # Detectar primer '|'             first_pipe = line.find("|")              # Caso sin '|': solo columnas con coma             if first_pipe == -1:                 parts = [p.strip() for p in line.split(",")]                 rows.append(parts)                 continue              # Separar en 2 bloques: coma y pipe             left = line[:first_pipe]      # columnas coma             right = line[first_pipe + 1:] # columnas pipe              left_parts = [p.strip() for p in left.split(",")]             right_parts = [p.strip() for p in right.split("|")]              combined = left_parts + right_parts             rows.append(combined)      # Normalización de longitud de filas     maxlen = max(len(r) for r in rows)     rows = [r + [""] * (maxlen - len(r)) for r in rows]      header = rows[0]     data = rows[1:]     return header, data`


**2. limpieza inicial:**

Normaliza encabezados (quita BOM y espacios).

`df.columns = [c.replace("\ufeff", "").strip() for c in df.columns]`

_2.2. Conversión de tipos de datos:_

Varias columnas numéricas venían como texto, algunas con , en lugar de .  
Se convirtieron a valores numéricos:

`def postprocess(df):     if "ticket_id" in df.columns:         df["ticket_id"] = pd.to_numeric(df["ticket_id"], errors="coerce")     if "day_of_week_num" in df.columns:         df["day_of_week_num"] = pd.to_numeric(df["day_of_week_num"], errors="coerce")      for col in ["company_id", "past_30d_tickets", "past_90d_incidents",                  "org_users", "customers_affected", "error_rate_pct", "downtime_min"]:         if col in df.columns:             df[col] = pd.to_numeric(df[col].astype(str).str.replace(",", "."), errors="coerce")     return df`

_2.3. Elimina columnas totalmente vacías:_

`empty_cols = [c for c in df.columns if df[c].eq("").all() or df[c].isna().all()]
df = df.drop(columns=empty_cols)`
